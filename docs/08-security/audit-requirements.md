# 审计要求

至少记录actor_id、org_id、case_id、action、object_type/id/version、outcome、request_id和带时区occurred_at。用户查阅、下载、上传安全拒绝、复核、审批、固化、报告/审计导出、回流、模型/索引发布、配置和恢复分别留痕。

审计事件只追加；普通业务运行角色不能修改/删除/截断。重要业务变更与outbox在同一事务建立关联；失败及拒绝也必须记录，审计管道不可用的正式操作策略待安全负责人确认，不能无声放行。

普通日志排除令牌、密码、签名密钥、完整对象访问凭据、原始敏感文本和不必要人脸/定位字段。审计查询和导出另需权限；业务管理员不默认具备审计导出能力。保留期限与监管要求待Q-19/Q-31确认。
