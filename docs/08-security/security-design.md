# 安全控制设计

公开依据见official-sources.md的W08/W09/W15/W16，适用法律、等保定级和公安厅内部准入尚待专责确认；不编造等级、密码测评或生产网络批准。

身份由服务端核验有效、禁用和撤销，功能权限与案件数据范围分别检查。客户端case_id、source_id及object_id只作请求标识；数据库角色不得为超级用户或BYPASSRLS。连接池每事务设置已认证actor/org，事务结束清除上下文。数据库SET能力只赋予受信后端，不能给终端用户直连。

上传按白名单扩展名、实际容器/编码探测、大小与资源预算、查毒和隔离处理；原件存受控对象版本。解析运行非特权、限制临时盘/进程/CPU/内存且默认禁止网络协议和shell拼接。

所有出站URL校验scheme/host/port/DNS/IP，拒绝内网非法地址、凭据、重定向跳过验证和重新解析绕过。当前不假设任何平台已有授权接口。页面和模型文字仅作为数据，不能调用审批或增加权限。

正式报告、固化、回流和模型发布分别核验有效目的授权、对象/策略版本及许可。下载使用受控代理，每个Range请求重新核验，no-store；已接收字节无法追回。预签名临时凭据不作为即时撤销机制。

证据与审计使用追加事实、指定对象版本摘要和受控保留；DB普通角色不可更新/删除/截断事实。DB超级用户与基础设施管理员仍可绕过或破坏，需外部审计、对象锁、离域备份和权限分离，不能靠SQL宣称绝对防篡改。
