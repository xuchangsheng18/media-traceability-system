# 模型评测协议

工程冒烟、流水线公式验证、开发基线、候选模型与独立业务验收分开记状态。协议需冻结样本清单摘要、模型/代码/预处理/阈值/索引、资源、统计单位、正负例、分组、失败计数和批准范围。未定目标为null/pending，不虚构通过线。

多标签Macro-F1按固定类别集合逐类计算再宏平均；空类别与零分母处理写入协议。重点类别召回单列，不用总体得分掩盖弱类。图片篡改逐图IoU宏平均；漏检正例IoU=0，负图误报单列，掩码映射原件并按面积分层。视频边界误差与召回、未命中和未知来源分别报告，不能删除失败样本。

检索Recall@K固定候选库、关系单位和授权范围；语义相似不算同源正确命中。首发Top-3以同簇、观察覆盖与人工真值定义，不等于全网原创准确率。主张字段F1、JSON有效率、引用存在与语义支持分别统计。

ECE记录分箱、类别汇总、空箱及比较条件；训练拟合数据和校准/阈值数据区隔。封存集只由验收角色受控使用，研发不可看作日常CI回归样例，不用于模型选择、参数、阈值或难例挖掘。

保留源95%/0.85、IoU0.70、检索95%/90%、边界1秒和首发90%等目标，但其正式分母与适用性仍按Q-13/Q-22确认。20/100并发、资源、GPU和预算另按Q-14/Q-29；本包不改变为可选扩展或已通过。
