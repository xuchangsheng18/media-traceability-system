## 文档说明

本清单为T125—T170算法模型研发与训练任务提供推荐技术选型。总体采用“一个首选模型、一个轻量备选模型、一个传统或可解释基线”的配置，并以可私有化部署、PyTorch生态成熟、能够输出帧、区域、时间和证据为主要选择原则。最终发布模型必须通过项目独立业务测试集比较精度、泛化性、推理时延、显存占用和可解释性后冻结。

### 模型选择原则

| 原则 | 要求 |
| --- | --- |
| 业务指标优先 | 以重点类别召回、Macro-F1、IoU、Recall@K和时间定位误差为主要依据。 |
| 证据可定位 | 模型结论必须能够回到帧、区域、时间段、匹配点或证据文本。 |
| 基线可比较 | 每条算法线保留传统或轻量基线，避免只与单一深度模型比较。 |
| 可私有部署 | 优先选择可离线部署、权重和代码许可清晰的模型。 |
| 可替换 | 通过统一推理契约接入，业务系统不绑定具体模型名称。 |
| 可校准 | 所有概率结论进行校准，并保留证据不足或不确定状态。 |

## 2 T125—T141风险识别模型

### 2.1 公共训练与基线模型

| 任务 | 传统或轻量基线 | 深度模型基线 |
| --- | --- | --- |
| 图片多标签 | ResNet50 | ConvNeXt-B |
| 目标检测 | YOLO11-S | RT-DETR-R50 |
| 视频行为 | 3D-ResNet | VideoMAE-B |
| 音频事件 | PANNs CNN14 | BEATs |
| 跨模态矛盾 | XLM-R文本分类 | Qwen2.5-VL |
| 风险融合 | 逻辑回归、LightGBM | Multimodal Transformer |


### 2.2 图片多标签风险分类

T129—T131首选ConvNeXt-B，在输出端设置多标签Sigmoid分类头。类别基本均衡时使用带类别权重的BCE；长尾明显时优先比较Focal Loss和Asymmetric Loss。Swin-B和ViT-B作为结构对照，ResNet50作为传统深度基线。

| 组成 | 推荐配置 |
| --- | --- |
| 骨干网络 | ConvNeXt-B |
| 输出头 | 多标签Sigmoid |
| 损失函数 | Weighted BCE、Focal Loss、Asymmetric Loss |
| 增强 | RandAugment、Mixup、CutMix和业务退化增强 |
| 指标 | Macro-F1、每类召回率、PR-AUC和校准误差 |


### 2.3 敏感目标和小目标检测

T132首选RT-DETR-R50，YOLO11-M作为轻量备选，Grounding DINO只用于开放词汇候选发现。T133采用RT-DETR与SAHI切片推理、多尺度训练和高分辨率特征层组合。超分辨率只能作为辅助实验，不能把生成细节直接当作取证证据。

### 2.4 视频行为与时间定位

T134—T136推荐“VideoMAE V2提取片段特征＋ActionFormer定位事件边界”。SlowFast和MViT V2作为对照，轻量部署可评估X3D。整段视频分类模型只能用于初筛，正式结果必须增加时间定位头。

### 2.5 音频事件识别

T137首选BEATs，多标签分类采用事件分类头；连续时间定位增加帧级TCN。AST和PANNs作为备选。模型应同时输出事件类别、时间段、置信度、音轨编号和模型版本。

### 2.6 跨模态矛盾与风险融合

T138—T139建议由Qwen2.5-VL抽取画面事件，XLM-R或DeBERTa NLI模型判断画面与标题、字幕、语音之间的一致、矛盾、无关和证据不足关系。T140先建立LightGBM融合基线，再训练Multimodal Transformer，避免在单模态模型尚未稳定时直接进行复杂融合。

| 模块 | 输入 | 推荐模型 | 输出 |
| --- | --- | --- | --- |
| 画面事件抽取 | 关键帧、目标和视频片段 | Qwen2.5-VL | 主体、行为、时间、地点、结果 |
| 文本主张抽取 | 标题、OCR和ASR | Qwen或XLM-R抽取模型 | 结构化主张 |
| 关系判断 | 画面事件与文本主张 | XLM-R/DeBERTa NLI | 四类关系及概率 |
| 风险融合 | 全部模型分数和质量特征 | LightGBM/融合Transformer | 风险类别、校准分数和证据 |


### 2.7 概率校准

T141首先使用Temperature Scaling，明显非线性时采用Isotonic Regression，多标签可评估Vector Scaling。校准和阈值只能使用验证集，独立测试集仅用于最终验收。

## 3 T142—T153篡改与深度伪造模型

### 3.1 图片篡改检测

T142—T146首选TruFor作为主基线，结合项目数据研发RGB语义、噪声残差和编码元数据三分支融合模型。RGB分支可使用ConvNeXt或Swin，噪声分支使用BayarConv、SRM或TruFor学习型噪声特征，分割头采用UPerNet或SegFormer Head。

| 分支 | 推荐模型或特征 | 主要作用 |
| --- | --- | --- |
| RGB语义分支 | ConvNeXt/Swin | 物体边缘、光照、阴影和空间关系 |
| 噪声残差分支 | TruFor噪声、BayarConv、SRM | 相机处理链和局部压缩不一致 |
| 编码元数据分支 | MLP编码JPEG量化表、EXIF和重采样 | 编辑软件和编码痕迹 |
| 融合模块 | Cross-Attention | 跨分支特征融合 |
| 分割头 | UPerNet/SegFormer Head | 像素级篡改掩码 |
| 可靠性头 | 置信度或不确定性网络 | 输出可靠性图和证据不足 |


联合损失建议由图像级分类损失、掩码BCE、Dice、边界损失和可靠性损失组成，权重通过验证集或不确定性动态加权确定。

### 3.2 视频时空篡改

T148采用VideoMAE特征与Temporal Transformer融合光流、帧间相似度、PTS/DTS、GOP、重复帧和音频连续性。T149采用TruFor逐帧定位，再使用XMem或SAM2进行掩码传播和跨帧聚合。SAM2只用于区域传播，不负责判断是否篡改。

### 3.3 深度伪造与音画同步

| 任务 | 首选模型 | 备选模型 | 训练重点 |
| --- | --- | --- | --- |
| 人脸深伪空间检测 | Swin/ConvNeXt | Xception、EfficientNet | 跨身份、跨生成器和强压缩 |
| 人脸深伪时序检测 | VideoMAE | FTCN、LipForensics | 帧间一致性和运动异常 |
| 音画同步 | VocaLiST | SyncNet、TalkNet | 口型、声音和时间偏移 |
| 综合融合 | 门控融合或校准加权 | LightGBM | 缺失人脸、无语音和证据不足 |


### 3.4 泛化与不确定性

T152采用压缩增强、MixStyle、域对抗、SAM优化器、SWA、模型集成和留一生成器训练。T153优先使用Deep Ensemble估计不确定性，资源受限时采用MC Dropout，并增加Energy-based OOD和Temperature Scaling。

## 4 T154—T165同源溯源与首发模型

### 4.1 图片复制检测

T154—T157首选SSCD作为同源复制向量，DINOv2或SigLIP作为语义补充向量。SSCD负责发现压缩、裁剪、镜像、水印、字幕和遮挡后的复制内容；语义向量只用于扩大候选召回，不能独立确认同源。

| 模块 | 推荐算法 | 说明 |
| --- | --- | --- |
| 全局复制向量 | SSCD | 主同源召回通道 |
| 语义补充向量 | DINOv2/SigLIP | 同事件或相似场景候选 |
| 训练损失 | InfoNCE、Circle Loss、Multi-Similarity | 结合复杂编辑正样本和难负样本 |
| 难负挖掘 | 在线或离线Hard Negative Mining | 重点降低同事件不同角度误判 |
| 索引 | Milvus IVF/HNSW | 按模型版本隔离并支持回滚 |


### 4.2 局部同源几何验证

推荐“SuperPoint＋LightGlue＋MAGSAC++”作为深度局部匹配主路径，同时保留“SIFT＋RANSAC”传统基线。最终验证分数综合内点数、内点比例、区域覆盖率、重投影误差和几何变换合理性。LightGlue可对SuperPoint、DISK等稀疏特征进行自适应匹配。

### 4.3 视频关键帧与片段定位

| 环节 | 推荐算法模型 | 输出 |
| --- | --- | --- |
| 关键帧复制向量 | SSCD/DINOv2视频适配模型 | 帧向量和Top-K候选 |
| 帧相似度融合 | LightGBM或小型MLP | 多通道相似分数 |
| 相似度矩阵 | 余弦相似度＋局部几何分数 | 查询帧×候选帧矩阵 |
| 可解释对齐 | 局部DTW＋Smith-Waterman | 对齐路径、速度、方向和边界 |
| 学习型定位 | Temporal Transformer | 粗定位与候选边界 |
| 多源边界 | TCN | 来源编号、未知来源和切换边界 |


正式系统建议用学习型模型进行候选定位，再用DTW完成精确边界和证据验证。不能用单个高相似帧确认视频同源。

### 4.4 同源聚类和首发排序

T164—T165先使用通过几何或时序验证的高可信同源边构建图，以连通分量或HDBSCAN形成内容簇。首发排序首选LightGBM LambdaMART，XGBoost Rank作为备选。输入包括时间可信度、完整度、分辨率、码率、音轨、水印、字幕、账号历史和传播图特征。

| 输出内容 | 要求 |
| --- | --- |
| Top-3候选 | 不得只输出唯一候选 |
| 排序分数 | 模型原始排序得分 |
| 校准概率 | 经Isotonic或Temperature Scaling校准 |
| 支持证据 | 时间、质量、音轨、水印和图谱证据 |
| 反对证据 | 时间冲突、采集覆盖不足等 |
| 不确定性 | 证据不足时禁止确定性原创结论 |


## 5 传播分析和证据核查模型

### 5.1 传播路径与关系推断

显式转发关系直接入图，不需要训练。关键节点使用PageRank，传播社区使用Louvain或Label Propagation，时间路径使用有向时序图搜索。隐式搬运关系先使用LightGBM或XGBoost融合同源度、时间差、水印、字幕和账号关系；数据充分后再评估GraphSAGE或GAT。

### 5.2 结构化主张抽取

T166—T167首选Qwen2.5-7B-Instruct进行LoRA微调，涉及图片或视频时采用Qwen2.5-VL-7B。资源充足时评估14B或32B，但7B更适合当前A100和4×RTX 4090环境下的私有部署。必须同时保留XLM-R或UIE非生成式基线。

### 5.3 证据关系判断

T168首选DeBERTa-v3-Large或XLM-RoBERTa-Large增加NLI五分类头，关系包括支持、反驳、部分支持、无关和证据不足。Qwen LoRA用于生成解释，不建议让大语言模型同时独立完成事实判断和解释。

### 5.4 无证据生成检测

| 层级 | 算法 | 检查内容 |
| --- | --- | --- |
| 第一级 | 确定性规则 | 事实句是否存在有效evidence_id |
| 第二级 | Cross-Encoder/NLI | 句子是否被引用证据支持 |
| 第三级 | Qwen等大模型复核 | 只处理边界和冲突样本 |


任何无引用、引用失效或不被证据支持的事实句均不得进入正式报告。
