# 固定历史证据分页及复核页面接线

本批为T101-C02后端分页与T103-C04前端翻页两个限定工程子步骤。T101开发负责人和指定复核人均由用户确认为徐昌胜；T103既有责任不变。这里只登记责任，不证明本人已复核、独立双人验收、工时或正式授权。原卡源算法依赖保留，算法与Python候选继续暂缓。

## 实际接口与兼容边界

复用GET /analysis/tasks/{id}/evidence及既有EvidencePage、limit、cursor和history深对象契约，没有新增端点、响应字段或数据库迁移。仅显式提供limit或cursor时启用分页；cursor单独提供时有效limit为20，limit范围为1—100。两项均省略沿用旧固定投影响应，包含其原有上游游标；不能将本批记为所有旧调用均已遵守默认20。

history仍可省略，按既有实现选择每次实际最新结果；旧游标绑定的任务/运行/结果与新最新不同则拒绝422，不把游标当版本选择器。显式历史精确读取，不命中404，不回退最新。前端始终传所选运行/结果和limit=20，下一页额外原样URL编码不透明cursor；不伪造case_id查询参数，案件由现有权限与真实仓库绑定。

## 完整投影、顺序和游标

现有仓库仍先在当前身份、单位、案件及来源/对象范围下验证完整固定快照。投影next_cursor非null表示上游未取得完整数据，显式分页返回EVIDENCE_PAGING_SOURCE_INCOMPLETE/503；不将生产方游标换成本地游标或null。省略分页参数保留原响应，是兼容路径，不是自动降级或完整性证明。

本地分页保持投影原顺序，分页前检查证据UUID重复。游标为位置8字节、完整规范化投影SHA-256摘要32字节和完整HMAC-SHA25632字节，使用现有严格解码器进行无填充URL-safe Base64编码；绑定专用版本标签、主体、单位、案件、任务、运行、结果及有效limit。复用既有cursor_secret，不在文档或日志导出密钥。非规范编码、MAC或绑定/位置不符返回422；MAC有效但摘要改变返回409，错误不暴露快照细节。游标是续页位置，不是授权，每页均重复当前授权和仓库验证。

本批是HTTP负载分页，完整快照仍需物化、校验与摘要；不是数据库流式读取、keyset查询、内存优化或大规模性能验收。未新增类型/人工状态过滤、算法发现或真实结果生产方。

## 页面行为

前端读取当前页后提供“下一页证据”。第一页不带cursor，后续页保持精确历史选择。请求中、无游标、身份/权限不足时不可翻页；每次读取清除旧页及已定位卡片，新页替换旧页，不累计合并。历史复核只显示本页匹配引用，缺编号表示当前页未定位，可继续查询，不证明全量不存在。最后一页next_cursor=null后禁用下一页。

每页继续校验三个历史响应头、17字段及逐证据案件/任务/运行/结果绑定。403/409/503、结构或绑定不符清除页与游标，展示错误，不回退旧模式或最新版本，也不显示成功空页。案件、任务、当前/历史来源、身份/角色/权限/成员关系、父页面或卸载变化清理旧状态，迟到的续页成功和错误均丢弃。受控对象、时间毫秒半开区间及归一化区域仍只作转义元数据，不下载或播放媒体，不从读取推断批准或证据法律效力。
