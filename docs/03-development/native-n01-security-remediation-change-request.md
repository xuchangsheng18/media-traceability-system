## 拟执行的具体范围

1. 另建Node22.23.3候选归档锁，核对官方摘要；在独立目录验证前端单元、构建及适用浏览器测试，不替换当前Node22.21.1路径或共享Web服务。
2. 使用官方Go1.27.2工具链，为age1.3.2制作独立修补构建候选：将x/crypto至少修补到0.56.0，并按Go模块解析结果锁定所需传递依赖。执行上游适用测试和合成数据的加密/恢复、错误密钥拒绝验证。
3. 对SeaweedFS4.48建立独立修补候选：Go1.27.2和x/net0.60.0，锁定全部解析结果；保留源码补丁、go.mod/go.sum、工具链和构建参数。通过隔离存储实例检查原S3上传/读取、版本对象、摘要、权限拒绝及恢复行为，不操作现用对象数据。
4. 用相同的已固定扫描器及新鲜数据库重扫候选，保留修补前后结果。任何仍适用的漏洞、缺失依赖或许可材料不能自动标为通过；发现必须改变额外公共行为或业务接口时另报冲突。
5. Python3.10与原100包锁保持，逐条校核CPE匹配；本轮不将不适用项的候选判断写成他人签认或正式安全批准。
