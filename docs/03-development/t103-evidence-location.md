# T103精确历史证据读取与编号定位

本批接续已入库T103只读工作台，开发负责人及指定复核人仍为徐昌胜，不登记本人已复核或独立双人验收。

从本次已读取的复核上下文或某条历史复核选择其精确任务、运行和结果版本，显式读取既有getTaskEvidence接口。历史沿用自身证据引用和版本，不回退最新；返回的三个历史绑定响应头及每条证据的案件/任务/运行/结果必须匹配。

证据元数据按既有17字段契约验证，包括受控对象标识与版本、摘要、映射/模型/授权版本和时间；区域为原件归一化x/y/width/height，校验相加不越界；时间为毫秒半开区间[start_ms,end_ms)，校验顺序。没有媒体时长，不声称校验了时长上界；证据摘要与对象摘要分别核对格式，不擅加二者相等要求。

当前上下文列本次返回证据，历史复核只定位其引用编号。缺引用明确显示为本次返回尚未定位；合法空响应与403/404/503失败分开。接口契约有分页字段，但当前后端拒绝limit/cursor，故本批不发送该参数；非空next_cursor明确提示未读取完整，不宣称取齐或提供失效翻页按钮。

本批只读证据事实及位置元数据。对象引用作转义文本展示，不构造直链、不下载媒体、不执行审批或模型；历史kind/model_name不当本轮新推理或当前批准。未认证、缺review.read/evidence.read或案件不可见时不发请求。父上下文/历史页重查、选择、任务/案件、本地身份权限与卸载变化均清理证据并丢弃迟到成功或错误。
