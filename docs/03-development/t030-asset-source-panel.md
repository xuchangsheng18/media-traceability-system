## 交付及复用

原资产详情只有source_id，并提示来源授权明细未接入。现在从已加载的当前案件/资产详情中取得source_id，用户点击后只调用已有`GET /api/v1/sources/{id}`，不增加case_id查询参数。服务端现有getSource路由、单位/案件授权及资源复核保持；本批没有后端、数据库、公共字段、权限策略或依赖锁变更。

| 文件 | 本批用途 |
| --- | --- |
| `frontend/src/business/asset-source.ts` | 只读控制器；当前资产与案件、独立权限、响应绑定及上下文代次保护 |
| `frontend/src/business/sources.ts` | 复用原严格Source校验；抽出sourceDetail供两个页面读取，同步/登记协议不变 |
| `frontend/src/components/AssetSourcePanel.vue` | 展示来源名称/类型、服务端状态、用途、依据编号、原始有效期和来源记录版本 |
| `frontend/src/views/AssetsView.vue` | 在已加载的资产详情内挂载面板；重读、切换及卸载清理生命周期 |
| `frontend/src/business/asset-source.test.ts` | 40项新增控制器测试，包括无请求拒绝和晚回复 |

后端依据：`controls/router.py`已有getSource，`controls/common.py`从真实source解析案件并核验resource scope。Source读取允许观察已过期/撤销记录本身；`source.read`与首发排序的`origin.read`不同，不能混用。

## 精确行为

- 要求已连接身份、asset.read及source.read；当前案件属于可见case_ids，资产详情已加载且不在重读中，case_id/asset_id与选择一致。请求来源只能取该详情的source_id，不能由输入框任意替换。
- 响应复用完整Source必填/枚举/版本/用途/有效期校验，并同时匹配source_id和case_id。缺字段、额外字段、错误来源或案件均拒显。
- pending、verified、expired、revoked按服务端值展示。expires_at为null显示“未提供”，不推断永久授权；不把读取记录或verified标签当作媒体下载、分析或训练许可。
- 授权依据、名称及用途通过Vue文本插值显示，不把来源文本变成可执行HTML或任意链接。面板不登记、不同步、不更改来源状态，不改变现有下载判定。
- 用户/组织/generation/角色/权限/可见案件、选择的案件/资产、详情字段与版本、加载/重读状态改变时清空来源记录。异步结果须仍匹配原上下文；离开组件后旧请求不能恢复数据。
- 刷新先清旧数据；403/404/503和网络错误显示既有安全错误信息，允许重新读取。不自动轮询或缓存ALLOW。
