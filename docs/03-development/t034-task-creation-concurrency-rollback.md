## 真实回滚、等待者创建与写集合

确认等待关系后释放持有者暂停门；在下一次task_run写入前注入明确的自有测试异常，要求同一异常对象向调用者真实传播。它不是业务漏洞RED，不修改产品异常路径或将错误吞掉。持有者事务真实回滚释放锁后，等待者继续使用自己当前仍有效的材料和请求创建，而非重放失败持有者的不存在回执。

独立提交态SQL核验八组完整写集合只属于等待者的一次创建，节点数量来自实际计划而非固定业务数值，task_result为0；失败持有者的task_id在全部相关集合为0，失败request_id在事件、审计、outbox和幂等回执中均为0。等待者Accepted/ETag、事件/审计及outbox请求标识一致归属于等待者，未发布outbox仍attempts=0，原A/B及规范材料字节绑定保持。所有工作线程必须完成后才能执行最终oracle与fixture回收，不以daemon或取消后的状态掩盖线程未完成。
