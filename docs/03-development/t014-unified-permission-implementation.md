## 当前实现

外部路径、方法、字段和41个权限码仍以[唯一OpenAPI](../03-api/openapi.yaml)为源。`Principal`绑定已认证的内部用户/单位、issuer、subject及到期时间；原T013 `authenticate()`兼容接口保留。统一`require_permission(permission_code)`保护当前42个业务操作，保留原单位RLS、案件成员、对象归属、来源/用途和后台执行重验。

当前73项契约/41权限/6角色的[逐操作矩阵](../08-security/t014-interface-scope-matrix.md)明确42项已挂载、31项未挂载；`devLogin`是唯一开发公开例外且尚未挂载。内部推理继续单独验证服务身份，框架文档和PoC健康入口不代替业务授权。启动审计拒绝未知、漏保护、重复/影子、额外挂载路由及关键依赖覆盖。

[0006迁移](../../backend/business_migrations/0006_permission_lookup.sql)创建`mt_permission_lookup`受限角色和`mt.lookup_permission`事实函数，0006版本为63业务表843字段。后续完整角色事实与事务代际增量见[0007—0008字典](../04-database/authorization-fence-extension.md)，不能把旧版本字段数当成全部新增后的结构。查询无管理/RLS绕过/直接表读写，无正式角色、用户或ALLOW种子。事实精确绑定用户、单位、权限、摘要及策略版本，变更后继续拒绝。共享数据库未执行本批迁移。

缺少有效身份401并附Bearer challenge；已认证缺功能许可403；缺策略或依赖故障503；对象越界按既有规则隐藏为404。无正式策略时保持拒绝，测试合成允许不作正式依据。
