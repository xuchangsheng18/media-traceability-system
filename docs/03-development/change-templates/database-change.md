# 数据库变更记录模板

复制到具体迁移记录并关联PR。初始化SQL只用于新隔离空库，既有数据库变更必须使用版本迁移。

| 字段 | 本次填写 |
| --- | --- |
| 变更编号 状态 实际负责人 | 实际编号；DRAFT；未知责任人留null |
| 数据库与迁移 | 实际隔离目标、前置版本、新迁移编号和摘要 |
| 表 字段 契约及任务 | 表/列、OpenAPI或Schema定位、映射与任务编号 |
| 现有数据与恢复依据 | 真实数据量/对象版本、备份摘要及恢复报告；没有则留待办 |

## 变更与兼容

说明当前结构、拟议结构、默认值/空值/约束及业务语义。列读写兼容期、回填方式、锁/时长/临时空间预算、索引及并发影响；不把设计DDL或空库通过当生产升级通过。

## 隔离和历史

检查单位/案件上下文、逐表RLS、复合外键、对象版本/摘要、追加历史、审批绑定和最小权限。跨案件关联、旧版本修改和越权访问必须被拒绝，不能靠普通请求参数声明授权。

## 执行与验证

写明先后顺序、目标校验、停止条件及事务边界。测试空库、旧版本升级、重复执行、约束反例、跨案件、并发/锁及失败恢复；记录真实命令、版本、前后行数/摘要和结果。禁止指向现有PoC或未获授权业务库作试验。

## 回退或前向修复

区分应用回退、数据回退和前向修复。对不可逆迁移提供真实备份/恢复和对账步骤，未验证不能称可回滚；原件、历史结果和审计不普通覆盖。列实际有权决定、维护窗口、责任人和证据，模板不授予生产执行权限。
