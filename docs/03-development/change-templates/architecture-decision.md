# 架构决策记录模板

| 字段 | 本次填写 |
| --- | --- |
| ADR编号 日期 状态 | 实际编号；PROPOSED / ACCEPTED_DEVELOPMENT / APPROVED_PRODUCTION / REJECTED / SUPERSEDED |
| 实际责任人及决定引用 | 未落实留null，不代签 |
| 适用环境和任务 | 明确研发/测试/生产及关联任务 |

## 背景与约束

说明实际问题、来源版本、功能/资源/安全/兼容约束和未确认条件。

## 备选方案和决定

至少比较可行方案、证据、成本和局限，写明选择、精确版本/来源及适用边界；研发采用不自动代表生产批准。

## 影响 验证与回退

列受影响组件、契约、数据/模型/权限、运维和任务依赖；记录实际检查命令及结果。给出停止/回退条件、旧制品与数据恢复办法、未验证项及后续责任。替代旧ADR时保留旧记录并建立关系。
