# T103原始证据关联资产与受控原件下载

本批实现T103-C06，接续证据固定历史、分页和复核表单。开发负责人及指定复核人沿用徐昌胜；不登记本人已经复核、实际工时、完成日期或独立双人验收。原170项任务、源依赖及完整验收要求保留。

复用既有GET /assets/{id}、GET /assets/{id}/content、Asset/Evidence/ObjectRef契约和createAssetDownload；不新增端点、后端方法、数据库迁移或正式提供者，不修改公共契约、原100包锁和CI门禁。关联详情及字节读取均由用户显式点击，定位不自动下载，不从ObjectRef构造存储地址。

本控件只对当前有效所选original证据开放：必须具备非空固定引用，且该证据sha256等于引用sha256。此条件是当前原件下载UI子范围，不是所有Evidence的普遍不变量；其他类型或摘要语义不同的证据仍可按既有元数据契约展示，但本控件不支持其内容读取，不回退其他原件。读取另需review.read、evidence.read、asset.read及当前案件范围；下载再需独立asset.download。客户端检查不授予权限，后端仍须逐次核验真实身份、来源、案件及对象。

关联资产必须满足完整字段结构、原始类型、VALID状态、精确案件/资产编号及对象编号、固定版本、摘要一致，大小为有效正整数。错配、结构异常或HTTP拒绝不产生可下载绑定。复用现有下载工具逐阶段校验当前选择、实际字节大小、SHA-256和固定对象ETag后才交浏览器保存；不内嵌图片、音视频或脚本，不提供播放、派生证据字节或时间轴跳转。摘要及引用一致也不证明来源授权、证据真实性、执法效力或正式批准。

每次页面分页、重新读取、证据/父来源选择、身份/单位/角色/权限/案件、导航及卸载变化均清理绑定与旧下载状态；同generation身份变化亦生效。详情、内容及摘要阶段的迟到成功或错误不能污染新选择或触发保存；重复点击受控。新浏览器用例包含自建原件下载流的实际字节核对、资格/绑定/权限拒绝、HTTP异常、大小/hash/ETag错误、晚响应/晚摘要及清理，不使用真实案件材料。

最终959项前端单元、开发/生产各172项传输浏览器以及类型、格式、构建结果、精确五文件摘要、一次独立源码复核和20项基础依赖摘要见[实测回执](../00-project/validation/t103-evidence-original-report.json)。两个浏览器模式重叠，不作独立样本叠加；自建传输夹具不等于Linux真实身份/来源/后端组合E2E。本批后端、SQL和共享下载工具未改，不重复整套未受影响数据库回归。Windows及Linux对同一原锁和工具执行npm诊断均有效0匹配，只是当时注册表响应的诊断观察，不替代本批精确提交托管CI或其他安全门禁，不继承all-CI通过。
