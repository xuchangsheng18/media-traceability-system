# 剩余11类接口实施范围

用户于2026-10-14授权按当前会话继续完善剩余接口。本批按真实代码、数据库访问、条件更新和隔离验证实施，不再把候选路径当可调用接口。原件、170任务、原100包运行锁和既有PoC保持。

| 缺口 | 本批可实施范围 | 保留的正式前置条件 |
| --- | --- | --- |
| IF-G02 | 案件内审批申请、读取、决定、撤销及追加历史，独立审批人和有效期检查 | 真实审批规则提供方；组织级模型审批另行接入 |
| IF-G03 | 复核列表、详情、聚合版本和追加复核，任务/运行/结果/证据绑定 | 真实复核策略；不自动升级正式报告资格 |
| IF-G04 | 反馈及审批当前状态读取、用途撤销检查 | 授权数据集/分割清单、真实回流执行器 |
| IF-G05 | 真实发布记录查询与发布适配协议 | 实际部署操作记录、制品和平台协议；不把健康当发布成功 |
| IF-G06 | 审计列表、导出作业、固定产物和受控Range下载 | 明确导出策略及有效审批；私有文件研发目标不替代生产对象存储 |
| IF-G07 | 当前身份/角色/权限/案件读取适配及一致性校验 | 正式身份平台、主体映射和撤销协议 |
| IF-G08 | 来源清单/详情、当前授权核验及权威同步适配 | 正式授权机构、用途依据和失效同步协议 |
| IF-G10 | 导入状态读取和有界第三方适配协议校验 | 真实平台账号、签名/网络/API协议 |
| IF-G11 | 节点执行记录、事件读取、租约/栅栏/取消等执行基础 | 全业务DAG、真实节点实现和完整消息部署 |
| IF-G12 | 策略草稿存储、唯一版本、读取ETag和定义解析 | 实际参数、策略生效批准及权威定义提供方 |
| IF-G13 | 34能力路由/Schema/身份/版本/对象/期限一致性验证，缺能力明确拒绝 | 实际模型执行器、数据、许可、资源及评测 |

实施顺序：共同授权/幂等/ETag基础 → G02/G03/G06/G12 → 其余读取和适配边界 → 隔离数据库/HTTP/失败验证 → 派生契约和导航 → GitHub CI及Linux同源核验。默认不注入测试身份、规则或模型；缺失依赖返回不可用，不产生模拟业务成功。

数据库沿用62表825字段的已版本化基础。新的约束或结构必须追加迁移；原0001/0002摘要不重写。完成报告区分本批技术子范围、正式接入、完整业务流程，13项正式缺口不会因本批子范围通过而自动关闭。
