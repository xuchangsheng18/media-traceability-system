# 模型测试场景

正常：每项能力的合法输入输出按schemas/model验证；模型与前后处理/映射一致；真实候选按固定协议复算分母与指标。
异常：分数超界、bbox越界、反向区间、无引用、错误能力/output_kind、失败含成功payload、缺失模态无原因、mock冒充正式、索引维度/版本不符、旧run提交与后端超时/OOM。

多模态：无音轨/语音/脸不视为普通算法失败；显示missing_modality或insufficient，正式报告资格另判断。取证原字节与允许副本对照；跨压缩、相机、平台、人物/生成器子组分别报告。
多源：A—Q—B片段链不合并A/B整内容簇；未知区段明确；组合父组整体隔离。
语言模型：JSON有效不等于事实正确；引用存在与语义支持分开，网页注入不改变权限。
数据：人工reviewed、用途verified、冻结holdout访问隔离；拟合/校准/选择数据与验收分开。

训练/真实推理/GPU与目标达标均未由本包执行；schemas/fixture自建例仅验证契约和边界。
