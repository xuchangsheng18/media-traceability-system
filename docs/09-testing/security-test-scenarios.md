# 安全测试场景

1. 身份过期/伪造/禁用：401且日志无令牌；功能无权限403；不因管理员角色放开案件范围。
2. 两个案件同hash/相似素材：列表、详情、duplicate_of、检索、证据与Range均不得暴露另一案件。
3. 创建有效任务后撤销授权：下一查询/下载/重跑拒绝，后台长任务提交前再核验授权版本。
4. 发出下载token后撤销批准，重新请求普通下载与Range：拒绝；禁止直接永久对象链接。
5. 审核员并发提交旧If-Match：412，不丢更新；旧结果批准不能用于新结果报告。
6. 缺失/失效审批策略、目的不符、职责冲突：正式固化/导出/回流/发布阻断；防误确认不代审批。
7. 恶意格式、路径穿越、压缩炸弹、查毒不可用：隔离/有界失败，不发布VALID资产；解析不得出站或执行shell注入。
8. URL重定向/DNS变化/内网地址、网页提示注入：出站验证拒绝；外部内容不能提高工具权限或发起审批。
9. 对象受锁版本删除、新版本/删除标记及专用损坏副本：分别验证拒绝、原引用不变及摘要告警，不关闭真实保留锁。
10. 审计更新/删除/截断、日志带密码或敏感原文：拒绝修改并脱敏；DB超级用户绕过能力另由治理控制。
11. 已消费operation_token再提交/过期/对象版本变更：拒绝，token仅存散列、一次性消费原子。
12. 回流无训练用途、未脱敏或与封存父组重叠：不得入训练集，保留拒绝记录。
