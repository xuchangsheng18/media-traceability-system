# 验收执行配置与缺项检查

[执行输入](acceptance-execution-inputs.json)覆盖24项协议；保留源目标，正式目标不自动复制源建议。逐指标填写实际批准依据、样本/独立组数/分层数、真值版本、源码/模型/索引/映射/阈值摘要、资源/负载、重复次数、区间方案、执行/复核人员及时间。

stage_one_controls.py生成逐指标NOT_EVALUABLE及具体缺项；必需输入为空时禁止PASS。资料填写完整也仅是READY_FOR_EXECUTION，须实际测量和复核后另出结果。20/100性质、可用率/RPO/RTO仍需真实决定。时间分位包含失败终态，未知/未结束单列；封存测试不参与调参或日常CI。协议公式见[24项测量定义](metric-protocols.md)。
