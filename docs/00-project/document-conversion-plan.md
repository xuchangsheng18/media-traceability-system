# 开发输入映射与转换要求

来源先按[原件清单](source-inventory.json)保护字节，再以[逐原件内容核对](stage-one/source-content-audit.md)确认文字、表格、批注、链接和媒体；章节到工程入口的逐行映射见[来源章节映射](stage-one/source-section-map.md)及[结构化索引](stage-one/source-section-map.json)。

当前映射是候选评审路由：每行必须有原件摘要、准确部件位置、原章节标题、实际存在的工程路径和未批准状态。变更原件后不得直接沿用旧指针；变更接口/字段时同步契约、SQL、任务和测试，并单独记录执行与来源的差异。170任务来源字段不随运行时选择而改写。

自动目录页码、页眉页脚和视觉版式分别登记；文字存在性不能当语义一致或视觉还原。章节可映射多个专题，范围和优先级需在评审决定中明确。
