# 工程术语表

源设计明确范围经工程表述整理，待业务复核；法律和公安业务概念不由此表自行认定。

| 编号 | 名称 | 英文 | 定义及边界 |
| --- | --- | --- | --- |
| G01 | 原始素材 | original asset | 接入时保留字节、对象版本和摘要；派生副本不是原件 |
| G02 | 派生素材 | derived asset | 从有权原件按可追溯参数生成；多父血缘允许多源输入 |
| G03 | 完全重复 | exact duplicate | 字节摘要相同；提示与结果复用仍需当前授权和版本核验 |
| G04 | 整内容同源簇 | full-content cluster | 通过整内容验证的关系；部分包含不能经闭包合并整簇 |
| G05 | 片段映射 | segment mapping | 查询与多个源时间或区域对应；未知区段显式表达 |
| G06 | 相似非同源 | similar non-source | 语义或画面相似但没有复制来源事实 |
| G07 | 首发候选 | first-source candidate | 在授权观察范围内的较早来源候选，不等于全网原创 |
| G08 | 模型置信分数 | model score | 模型输出分数，校准与阈值版本另记录，不是法律概率 |
| G09 | 业务复核 | review | 人工核验当前结果和证据；不自动批准导出/回流 |
| G10 | 审批 | approval | 按用途、对象版本、策略和人员权限作决定；二次确认不替代 |
| G11 | 证据固化 | evidence sealing | 绑定指定版本及摘要的技术操作，不自动赋予法定证据效力 |
| G12 | 运行版本 | run version | 一次重算/执行实例的版本；旧运行结果不能覆盖新运行 |
| G13 | 结果版本 | result version | 结果/证据集合快照；批准与报告关联该版本 |
| G14 | 映射版本 | mapping version | 派生坐标和时间返回原件所用变换定义 |
| G15 | 校准集 | calibration split | 用于拟合校准器，与训练拟合区隔；独立验收集不参与 |
| G16 | 封存测试集 | holdout | 由验收角色受控使用，不能训练、阈值选择或难例挖掘 |
