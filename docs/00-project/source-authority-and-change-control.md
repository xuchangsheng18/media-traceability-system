# 来源版本与工程变更规则

本轮依据用户授权确定当前仓库的工程结构源；正式业务依据尚未确认。10原件及14历史文件保持字节不变。[来源登记](source-authority-register.json)保存身份、原件摘要、文件名版本及正文版本差异。

总体设计V1.4与任务书V1.3成对解释当前技术输入；历史文件名V2/正文V1.0均如实登记，不能按数字自动宣布其中一个正式权威。HTTP结构编辑OpenAPI，模型编辑schemas/model，数据集编辑schemas/dataset，物理数据库编辑DDL/表目录并经过迁移，任务原字段保留。当前用户选定py310属于研发执行选择。

每次变更登记变更ID、原因/依据、原位置、新工程定义、影响契约/表/任务/测试、兼容/迁移/恢复、验证报告和源码摘要。角色责任与实际姓名分开；未指定姓名保持null。没有有效业务决定时，冲突作为未决事项，不自动放行正式动作。新字段必须同步对应结构/映射/类型/测试，不覆盖历史。
