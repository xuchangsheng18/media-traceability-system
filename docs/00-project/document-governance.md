# 资料来源与变更管理

版本：0.1；整理日期：2026-10-12；状态：规划草案，NOT_FROZEN。

依据优先级应按适用范围判断：当前用户授权确定本轮工作范围；有效业务决定确定已确认规则；当前成对修订稿定义设计及任务语义；候选机器契约供结构校验。候选契约与正文冲突时登记并协调，不自动把候选实现当已批准业务规则。

原始业务资料、当前修订Word、流程手册分开归档；转换稿用于检索，表图和源身份以对应原件核对。docs/source原件本轮按字节保留，通过source-inventory.json校验。旧修订版保留在本地历史成果中，不混入当前执行入口。

本轮新增架构与部署文档是组织性提案。已有输入包全量按相对路径保留；修改或补充文件可与upstream-file-manifest.json比较。历史校验位于validation/upstream，本轮结构校验另有报告，不能拿历史SQL运行结果冒充本次执行。

文件状态区分：规划候选、已形成文件、结构已验证、实现已验证、正式确认。它们不是同一状态。当前NOT_FROZEN，业务任务未实现，不补写签字或负责人。

文档变更记录原因、来源、影响任务/API/表/模型、验证范围及遗留事项。源任务文本中的历史路径可以保留为引用，但实际工程落点以repository-layout为准；本轮对可识别的旧docs/architecture路径增加迁移说明，避免误建第二套架构目录。
