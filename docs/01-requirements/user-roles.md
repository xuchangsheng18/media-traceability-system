# 角色权限与审计补充

来源：详细设计第2.3及第10章。先保留原文角色职责，未覆盖的具体操作不推定已授权。

| 角色 | 核心权限 | 限制 |
| --- | --- | --- |
| 案件核查人员 | 创建任务、查看授权数据、提交审核意见、生成报告 | 仅访问所属单位和授权案件 |
| 业务审核员 | 复核算法证据、确认或驳回结论、发起会审 | 不可修改原始证据 |
| 数据管理员 | 数据源登记、分类分级、生命周期和脱敏策略 | 不可修改模型结论 |
| 算法管理员 | 模型注册、评测、阈值、灰度和回滚 | 原则上不可查看未脱敏案件内容 |
| 系统管理员 | 用户、角色、配置、服务和备份管理 | 业务内容访问需单独授权 |
| 审计员 | 只读查询操作、导出、模型和证据日志 | 不可执行配置变更 |


具体权限矩阵见docs/08-security/permission-matrix.md；角色存在不代表已授予所有操作。

T011已补[用户角色与数据范围模型](../08-security/access-control-model.md)、[机器评审矩阵](../08-security/access-control-model.json)及专属合成评审测试。六角色代码、职责映射和数据分类槽为候选设计；不代表正式账号或生效授权。当前执行状态见[任务卡](../../tasks/platform/T011.md)。
