# UC-REVIEW-001 REVIEW用例

状态：待评审设计；未执行。角色：前后端/算法平台,前端,后端,后端/安全,大模型/后端,安全/后端

前置：来源与用途授权、角色功能权限及案件范围有效；测试版本固定；无真实敏感材料。触发：有权用户执行该模块操作。

输入及处理：

## FR-REVIEW-001 人工复核会审及退回重算

正常输入：审核员对当前run/result版本提交附理由、证据的复核意见
主体与流程：用户提交；系统核验当前功能/对象权限和版本，执行关联能力；用户读取结果或人工处理。
正常输出：追加review_version，结果显示复核身份；不自动批准训练或导出
异常输入：同一人防误确认被当独立会审；或复核旧结果版本
异常输出：按有效策略拒绝或待审，412/审批角色冲突；旧结果不覆盖
备选：证据/模态不足保留未知，按规则转人工或部分完成；不虚构缺失来源。
权限：对应API的x-required-permission及有效案件授权；管理员不得默认越权。
审计：提交、权限拒绝、复核、版本变更、下载与导出分别记录request_id、主体、对象和结果。
测试：TC-REVIEW-001-N / TC-REVIEW-001-E。

异常输入：删除受锁version_id、创建同key新版本、专用副本故意损坏
异常输出：删除拒绝；新版本不改变原证据引用；副本摘要告警，不关闭真实锁
备选：证据/模态不足保留未知，按规则转人工或部分完成；不虚构缺失来源。
