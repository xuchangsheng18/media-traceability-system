输入及处理：

## FR-INGEST-001 登记来源与授权用途

正常输入：授权来源SYN-A，purpose含analysis且有效期覆盖请求；输入无敏感合成图片
主体与流程：用户提交；系统核验当前功能/对象权限和版本，执行关联能力；用户读取结果或人工处理。
正常输出：登记后创建上传会话，记录授权版本
异常输入：同一来源改为expired或purpose不含analysis
异常输出：拒绝接入，AUTH_FORBIDDEN；不建立可分析资产；审计含拒绝原因
备选：证据/模态不足保留未知，按规则转人工或部分完成；不虚构缺失来源。
权限：对应API的x-required-permission及有效案件授权；管理员不得默认越权。
审计：提交、权限拒绝、复核、版本变更、下载与导出分别记录request_id、主体、对象和结果。
测试：TC-INGEST-001-N / TC-INGEST-001-E。

异常输出：分别拒绝UPLOAD_HASH_MISMATCH或AUTH_FORBIDDEN，不能覆盖已有分片
