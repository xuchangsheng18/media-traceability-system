## FR-RESOURCE-001 管理原始及派生媒体

正常输入：原件A生成缩放派生B，记录父ID、代码摘要与mapping_version

正常输出：A摘要不变，B独立object_id并可回查A
异常输入：尝试更新A的sha256或object_id
异常输出：写入被拒绝；更正通过新对象表达
备选：证据/模态不足保留未知，按规则转人工或部分完成；不虚构缺失来源。
