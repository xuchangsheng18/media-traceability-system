## FR-MEDIA-001 解析媒体元数据并保留原件

正常输入：合成图片含EXIF旋转；VFR视频含非零start_time，保存原始stream time_base
主体与流程：用户提交；系统核验当前功能/对象权限和版本，执行关联能力；用户读取结果或人工处理。
正常输出：解析元数据并记录原始时间与估算标志
异常输入：畸形EXIF或缺PTS；不允许把帧号除平均fps作真实时间
异常输出：保持原件，记录缺失/估算原因；解析不能无限耗时
备选：证据/模态不足保留未知，按规则转人工或部分完成；不虚构缺失来源。
权限：对应API的x-required-permission及有效案件授权；管理员不得默认越权。
审计：提交、权限拒绝、复核、版本变更、下载与导出分别记录request_id、主体、对象和结果。
测试：TC-MEDIA-001-N / TC-MEDIA-001-E。
