输入及处理：

## FR-VIDTRACE-001 按关键帧召回候选来源

正常输入：视频A的关键帧库与查询变速片段Q，固定抽帧和向量版本
主体与流程：用户提交；系统核验当前功能/对象权限和版本，执行关联能力；用户读取结果或人工处理。
正常输出：候选按视频聚合并保存查询及源区间
异常输入：只单帧高相似但前后不一致或素材不在授权范围
异常输出：不形成确定来源；授权过滤优先且候选不泄露
备选：证据/模态不足保留未知，按规则转人工或部分完成；不虚构缺失来源。
权限：对应API的x-required-permission及有效案件授权；管理员不得默认越权。
审计：提交、权限拒绝、复核、版本变更、下载与导出分别记录request_id、主体、对象和结果。
测试：TC-VIDTRACE-001-N / TC-VIDTRACE-001-E。
