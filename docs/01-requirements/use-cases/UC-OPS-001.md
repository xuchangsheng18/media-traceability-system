## FR-OPS-001 管理角色模型标签阈值规则

正常输入：有功能权限的管理者注册模型/策略草案，不访问案件内容
主体与流程：用户提交；系统核验当前功能/对象权限和版本，执行关联能力；用户读取结果或人工处理。
正常输出：版本唯一、许可和配置引用完整，草案不能自动上线
异常输入：系统管理员没有案件授权却要求访问原件；许可不明模型上线
异常输出：默认拒绝；AUTH_FORBIDDEN或LICENSE_UNVERIFIED
备选：证据/模态不足保留未知，按规则转人工或部分完成；不虚构缺失来源。
权限：对应API的x-required-permission及有效案件授权；管理员不得默认越权。
审计：提交、权限拒绝、复核、版本变更、下载与导出分别记录request_id、主体、对象和结果。
测试：TC-OPS-001-N / TC-OPS-001-E。

异常输出：旧结果被fencing拒绝，日志脱敏；不产生重复业务效果
