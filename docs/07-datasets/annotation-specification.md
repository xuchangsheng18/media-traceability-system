# 标注与仲裁规范

各D01—D15独立Schema区分分类、框、事件、矛盾、原图编辑掩码、视频编辑、人物轨迹、复制关系、片段映射、多源拼接、首发簇、主张、证据关系和难负样本。每记录含sample_id、asset_ids、所有source_group_ids、用途授权引用、标注版本、状态、reviewer_refs与质量标签。

标签需定义、正例、反例、边界与不可判定条件；业务标签词典目前未批准，Schema只检查版本化标签字段，不编造违法类别定义。模型预标注只是候选，reviewed必须有人工记录；高风险/篡改/同源/首发双人独立标注与仲裁的正式范围仍按Q确认。

图片坐标归一化，框必须在原件内；像素掩码保留尺寸与原图映射。毫秒区间半开且起止有效、不得越过素材时长；倒放/变速保留direction/speed_ratio及mapping_version。多来源样本记录每一父组，缺来源不编造。首发候选发布时间可未知，保留覆盖说明。

难负样本只有human_confirmed=true且reviewed才作为人工真值候选；独立验收集不得挖掘难例。争议与不可判断不得强制改成正负类别。质检记录抽样策略、分层一致性和错误类型；一致性通过阈值待确认，不自行填数。
