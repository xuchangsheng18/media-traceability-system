# 实际可用数据与数据卡

[实际输入登记](actual-input-inventory.json)及[data-cards](data-cards/)覆盖D01—D15。仓库当前只有规划目录和合成训练证据；没有提供可核验的授权真实样本清单，因此业务样本数为null，不能写0或20万已到位。已有64条synthetic-uniform-16d训练证据单列为工程验证，不计为正式数据集。

每张数据卡填写来源/用途依据、授权状态、授权清单摘要、原件/派生/样本/标注/簇及独立组计数、各集合计数、标签/质检、质检合格数、切分清单、责任人和到位日。只对有权元信息清单计数，不扫描或提交真实敏感内容。

原件按唯一asset_id、派生按派生asset_id、样本按sample_id、标注按annotation_id/标签版本、内容簇按cluster_id分别去重。样本与标注不合计为独立原件；多个父组、人物和事件都纳入防泄漏；sealed_test不得训练/校准/回流。质检通过且用途有效才可进入相应合格计数。15目录尚未发布或冻结；实际授权和数据到位后再复算。
