# ADR-013 仓库结构

2026-10-13；状态：待批准。与现有TB-ADR系列分别编号，不覆盖任何已登记决定。

背景：已有用户指定GitHub仓库及py310 CPU工程，多服务契约、配置和验证需要同一来源。方案：研发沿用Monorepo，增加data-pipeline/tools的职责说明，保留现有全部12模块/170任务、13个原业务目录及其文件位置。

影响：跨模块契约变更可在同一提交核验，普通CI不要求GPU；Git不能提供按目录严格不可读取隔离。权重、素材、私有运行配置和大型制品外置。独立发布/保密边界确立后，按接口版本/数据迁移/构建和回滚计划再决定拆分。

批准人、批准日期、实际团队、正式代码平台和权限策略：均未确定。用户的当前工程同步授权不等于正式仓库治理批准。详细比较见[结构决策](../../03-development/repository-structure-decision.md)。
