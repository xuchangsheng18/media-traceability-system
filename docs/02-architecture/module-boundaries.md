# 十二模块职责映射

版本：0.1；整理日期：2026-10-12；状态：规划草案，NOT_FROZEN。

模块编号沿用现有需求和用例。表中归属是规划拆分；具体操作ID、表名和任务关系以[追踪矩阵](../00-project/requirement-traceability.md)和[字段映射](../04-database/api-field-mapping.md)为准，不在此创建不一致的第二套编号。

| 模块 | 名称 | 负责内容 | 关键边界 |
| --- | --- | --- | --- |
| INGEST | 多源接入 | 授权来源、上传、分片与批次 | 上传校验后交付资产 |
| RESOURCE | 数据治理与资源库 | 媒体、派生对象、版本及血缘 | 原件与分析副本分离 |
| MEDIA | 媒体预处理 | 探测、抽帧、OCR/ASR映射 | 统一源时间轴和坐标 |
| RISK | 多模态风险识别 | 候选标签、分数、证据区域 | 标签与阈值待业务确认 |
| FORENSIC | 篡改与深伪 | 检测结果及定位证据 | 区分原件和标准副本输入 |
| IMGRET | 图片同源 | 召回及几何验证 | 语义相似不等于同源 |
| VIDTRACE | 视频片段溯源 | 片段匹配与时序对齐 | 保留查询与来源区间 |
| ORIGIN | 首发候选 | 观察范围内候选排序 | 不直接判定原创 |
| PROPAGATION | 传播分析 | 关系与时间线 | 显式关系和推断边分开 |
| CLAIM | 谣言证据核查 | 主张与检索证据关系 | 证据不足保留未知 |
| REVIEW | 审核与证据 | 复核、版本固化、报告 | 正式结论按审核流程 |
| OPS | 综合运维 | 角色、配置、审计、模型版本 | 权限与数据范围并行核验 |

前端按模块组织页面，后端负责业务编排和权限，算法相关模块通过内部推理契约调用能力。REVIEW统一消费版本化证据；OPS提供横向能力但不替代业务审批。每个模块的实际负责人和接口实现进度由任务卡落实。
