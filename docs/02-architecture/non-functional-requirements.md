# 第二阶段非功能要求与测量口径

需求唯一来源保持 [非功能需求](../01-requirements/non-functional-requirements.md)。本文只登记研发验证方法和适用边界，不新增一套正式指标。

| 需求 | 本轮实际验证 | 仍需补充 |
| --- | --- | --- |
| SEC / AUDIT | Bearer 缺失/错误拒绝；内部推理需独立令牌；请求 ID 与安全错误；开发凭据仓库外 | 统一身份、单位/案件授权、撤销、审计留存、防篡改及双人审批 |
| AVAIL | 同键同资产返回同任务；不同资产 409；事务 outbox；队列中断后恢复；过期租约恢复；版本对象与结果重启持久化 | 多 worker 抢占、旧租约 fencing、取消、死信、集群失效及备份恢复 |
| COMPAT / MAINTAIN | py310 精确依赖检查；干净 venv 安装；类型、契约、SQL、构建及集成门禁 | 新版 Python 迁移与完整业务接口兼容 |
| AI / DATA | 真正执行 PyTorch 合成训练和推理，输出 mock=false、模型/映射版本；只用自建数据 | 正式业务模型、授权权重、封存评测、概率校准和指标定值 |
| PERF / DEPLOY | 容器资源限制及运行时点快照；CPU 单任务闭环 | P50/P95/P99、吞吐、峰值、20/100 并发与 GPU；未进行这些验收 |

推理响应 latency_ms 仅计内部方法，不含上传、排队、轮询和全链路时延。CI 报告中的耗时是门禁执行耗时，不能代替业务性能。CPU 合成模型的重建损失不是同源检索准确率。
