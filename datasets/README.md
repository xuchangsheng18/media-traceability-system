## 第二阶段应形成的文件

下面的路径或名称是计划交付位置，未形成时不能当作可运行文件。

| 计划交付 | 内容与要求 |
| --- | --- |
| `catalog/与索引` | 同步数据ID、用途、对应模型、来源和已核验数量 |
| `数据卡及划分引用` | 标注版本、source_group、用途和防泄漏清单的受控引用 |
| `最小验证数据说明` | 只使用合成或已获用途授权的样例，记录摘要和操作 |
| `环境和访问约束` | 指定实际存储路径、只读权限和用途，不写真实访问秘密 |

## 依赖和待补事项

具体版本、产品、资源及适用环境以技术候选、相关ADR和实际验证落实。未知项保留待确认；目录说明完成只代表本目录规划输入已补齐。每项交付记录版本、来源、运行命令、结果、未执行项和影响。

## 使用边界

预算样本数不等于实际数量；目录状态不能自动改成frozen；封存测试集不参与训练、调参或校准。

## 本轮数据与训练范围

本轮只用自建PNG、1秒合成视频和64条随机16维张量。实际PyTorch训练实验见docs/00-project/validation/synthetic-training-experiment.json；权重在专用model-data卷。没有接入真实案件、第三方业务权重或封存验收集，也未验证业务数据指标。后续正式数据仍遵守既有数据卡、授权、父组划分及防泄漏要求。
